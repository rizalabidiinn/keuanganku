# KeuanganKu - iOS Financial Tracker & Goals App 💸🎯

Aplikasi pencatatan keuangan harian, analisis grafik interaktif, dan goals tabungan dengan animasi smooth bergaya native iOS.

## 🚀 Fitur Utama
- **Ringkasan Saldo**: Apple Wallet style card dengan privacy blur mode.
- **Pencatatan Cepat**: Pemasukan dan Pengeluaran dengan kategori & ikon lengkap.
- **Goals Tabungan**: Target tabungan dengan progress ring, countdown sisa hari, setor celengan cepat, dan animasi selebrasi **Confetti**.
- **Analisis & Grafik**: Tren arus kas 7 hari & Donut Chart distribusi pengeluaran.
- **Desain iOS**: Glassmorphism, Dynamic Island, spring animations, modal sheets, dan efek suara haptik.
- **Ekspor Data**: Backup JSON & Ekspor riwayat ke CSV/Excel.

## 📱 Cara Menjalankan
Lihat panduan lengkap di [PANDUAN_LENGKAP.md](PANDUAN_LENGKAP.md).

1. **Jalankan di PC / iPhone lokal**:
   - Dobel klik file `start_app.bat`
   - Buka alamat yang tertera di Safari iPhone dan pilih **"Add to Home Screen"**.
2. **Build Paket `.IPA`**:
   - Push repository ini ke GitHub.
   - GitHub Actions akan otomatis meng-compile file `KeuanganKu.ipa` melalui workflow `.github/workflows/build-ipa.yml`.
