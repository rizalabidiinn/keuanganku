📱 Cara Jalankan di iPhone & Build .IPA
Opsi 1: Langsung di iPhone (PWA Standalone - 100% Gratis & Instan)

1. Hubungkan iPhone & PC ke Wi-Fi yang sama, atau deploy ke Vercel/GitHub Pages.

2. Buka link web di Safari iPhone.

3. Tap tombol Share (Bagikan) di bawah Safari.

4. Pilih "Tambah ke Layar Utama" (Add to Home Screen).

5. Aplikasi akan langsung terinstall sebagai aplikasi mandiri berlayar penuh tanpa URL bar Safari, lengkap dengan ikon!

Opsi 2: Kemas Menjadi File .IPA (Native iOS App)

Di dalam folder proyek ini sudah kami siapkan template Capacitor dan GitHub Actions.

1. Push folder proyek ini ke repositori GitHub Anda.

2. GitHub Actions akan otomatis meng-compile file .ipa di cloud macOS gratis!

3. Anda dapat menginstall file .ipa tersebut via AltStore, Sideloadly, TrollStore, atau akun Apple Developer.
